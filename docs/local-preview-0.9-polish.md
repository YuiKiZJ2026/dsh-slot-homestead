# 0.9.0-preview.2 本地细节优化

日期：2026-09-07。仅本机体验，没有推送、发布或替换正式 DSH 存档。

## 体验入口

打开 `/native-preview.html`，点击「补满测试资源」。这是可重置的模拟沙盒，不是正式存档。

- 在老虎机下方打开工具抽屉 → 工坊：试试「居民」分类，点击居民图片，逐个查看成长阶段。图片参考不会改变真实成长值。
- 在手账 → 种植计划：田地图像对应当前阶段，成熟后可以直接收获。
- 去工坊买另一种种子，让一块已有作物的田地预约下一茬，再点「撤销预约」。当前作物保留，肥料最多退回 1 份，库存最多 999。
- 操作成功后，桌面底部出现短提示。收获提示中的钱包数是两次确认状态之间的净变化，不冒充单次作物卖价。
- 在设置中开启减少动画，新增反馈仍可读但不会移动。系统的减少动态效果偏好也有效。

## 本轮图片范围

改善图集展示与分帧查看：12 种居民像素预览、可放大的成长图鉴、种植手账中的真实阶段外观。

同时精修原生动物 SVG：青年/成年鸡的分层羽毛、兔子的耳内绒毛与脚趾、羊驼的毛簇与蹄部。幼年分帧不动，600×600 图集与 200×200 分格保持原样；像素对比的透明度变化为 0，两份运行时源文件一致。没有重绘整套场景，也没有提高已有位图的原始分辨率。

尝试通过内置图片生成器创作透明底粗布肥料袋，服务连接失败，未产生或采用输出。未切换到需要额外 API 密钥的备用调用。
